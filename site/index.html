Tier 1, 2 and 3 countries as data

Every ISO 3166-1 country plus Kosovo, with its advertising tier, ISO codes, World Bank income group and EU and EEA membership. Search and filter below, then copy a geo-target list as JSON or CSV. The page runs the repo's own JavaScript helpers on the same data files it ships.

    What it is for

    Three jobs a rewards app, site, game or community can hand to this dataset.

    • Explain earnings by country

      Look up the tier of each user's country with tierOf() and compare earnings per user between Tier 1, 2 and 3 markets.

    • Build geo-target lists

      geoTargets() turns one or more tiers into a sorted list of ISO codes, ready to paste into a campaign or an offer's country field.

    • Handle EU consent by country

      The EU, EU territory and EEA fields tell you whether a GeoIP country code falls under EU rules, including areas such as Réunion and Åland.

    Output

    Use it in your project

    The helpers read data/countries.json, have no dependencies and return the same results in JavaScript, PHP and Python.

    Install (Node 22+)
    npm install github:moonetix/country-tiers
    Use
    import { tierOf, isEU, incomeGroup, geoTargets } from 'country-tiers';

tierOf('US');                       // 1
isEU('GP', { territories: true });  // true
incomeGroup('IN');                  // 'Lower middle income'

geoTargets(1, { exclude: ['LI', 'MC'], include: ['JP'] });
geoTargets([1, 2], { alternates: true, format: 'iso3' });
    Get it (PHP 8.1+)
    git clone --depth 1 https://github.com/moonetix/country-tiers.git
    Use
    <?php
require 'country-tiers/php/CountryTiers.php';

use CountryTiers\Tiers;

Tiers::tierOf('US');        // 1
Tiers::isEU('DE');          // true
Tiers::incomeGroup('IN');   // 'Lower middle income'
Tiers::geoTargets(1, ['exclude' => ['LI', 'MC'], 'include' => ['JP']]);
    Get it (Python 3.8+)
    git clone --depth 1 https://github.com/moonetix/country-tiers.git
    Use
    import sys
sys.path.insert(0, "country-tiers/python")
import country_tiers as ct

ct.tier_of("US")          # 1
ct.is_eu("DE")            # True
ct.income_group("IN")     # 'Lower middle income'
ct.geo_targets(1, exclude=["LI", "MC"], include=["JP"])
    Tier 1 as a comma-separated list, no install
    curl -s https://raw.githubusercontent.com/moonetix/country-tiers/main/data/tier1.txt | paste -sd, -
# AT,AU,BE,CA,CH,DE,DK,FI,FR,GB,IE,IS,LI,LU,MC,NL,NO,NZ,SE,US
    Filter the full file with jq
    curl -sO https://raw.githubusercontent.com/moonetix/country-tiers/main/data/countries.json
jq -r '[.[] | select(.tier == 1 and .eu_member) | .iso2] | join(",")' countries.json
# AT,BE,DE,DK,FI,FR,IE,LU,NL,SE

    tierOf() and incomeGroup() return null (None in Python) for a code that does not exist, and geoTargets() throws on one, so a typo never stays in a geo-target unnoticed. The README lists every helper and option.

    Data and sources

    Plain files you can download, and where each field comes from.

    Download the data

    • countries.json One object per country, all fields.
    • countries.csv The same as CSV, UTF-8.
    • tier1.txt, tier2.txt, tier3.txt ISO alpha-2 codes, one per line.
    • countries.schema.json JSON Schema for countries.json.
    • sources.json Source versions, licenses and the last update date.

    Tiers are an industry convention, not an official standard. Networks draw the lines a little differently, which is why contested placements are marked.
